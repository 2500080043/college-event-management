# College Event Management System

A simple three-page college event management system for a Git/GitHub practical.

## Pages
- `index.html` — home page
- `user.html` — student event registration
- `admin.html` — administrator event management

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Git practical
This project is intentionally suitable for demonstrating:
1. Git initialization
2. Remote repository setup
3. Branch creation
4. Commit history
5. Fetching remote changes
6. Reviewing branches and commits
7. Merging a developer branch
8. Demonstrating the final website
